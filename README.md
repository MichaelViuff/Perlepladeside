# Perlegalleriet

En enkel, statisk hjemmeside til at vise perleplader og gemme favoritter lokalt i browseren.

## Lokal visning

Åbn `index.html` direkte i en browser. Projektet bruger kun HTML, CSS og JavaScript og kræver derfor ingen installation eller byggetrin.

## Funktioner

- Responsivt galleri med eksempelmotiver
- Stor billedvisning i et modalvindue
- Favoritmarkering fra både galleri og stor visning
- Separat visning af favoritter
- Lokal lagring med `localStorage`

Siden indeholder ingen serverkode og kan udgives direkte med GitHub Pages.
